## Setup
1. Clone repo
2. cp .env.example .env
3. Fill env variables
4. npm install
5. npm run dev

## Supabase Setup
Run `/supabase/migrations/` SQL files in order in Supabase SQL Editor

## Tech Stack
- React.js + Tailwind CSS
- Supabase (DB + Auth + Storage + Realtime)
- Claude AI API
- Google Drive API
- Vercel (Hosting)
